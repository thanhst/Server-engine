# Game Transport đã đổi tên thành Datagram Transport

Xem [hướng dẫn Datagram Transport](datagram-transport.md) để build, chạy ví dụ
và đọc đường gọi ABI mới tới backend GNS.

Module truyền message dùng chung cho client/server, không chứa logic game.
Tên header/API GameTransport/se_game_* cũ còn được giữ để tương thích.
