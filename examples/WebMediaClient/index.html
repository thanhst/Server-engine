ServerEngine: một DLL, hai module

Ví dụ web dùng HTTPS, truy vấn nền qua Data, và gọi audio/video qua WebRTC.

1. Web API → SQL → kết quả

Endpoint chỉ đọc một profile mẫu, không phải chức năng đăng nhập.

Chưa gửi yêu cầu.

2. Truyền dữ liệu nhị phân

Chọn file audio/video bất kỳ. Demo gửi tối đa 16 KiB đầu tiên qua HTTPS rồi kiểm tra byte trả về; không upload hoặc lưu cả file.

Network vận chuyển byte, không tự giải mã video.

3. Audio/video trực tiếp giữa hai tab

Demo có một phòng chung, tối đa hai người, chưa có tài khoản hay phòng riêng. Chỉ dùng thử với người bạn chủ động cho tham gia.

Mở hai tab trên cùng máy. WSS chuyển SDP/ICE; WebRTC truyền media. Demo không cấu hình STUN/TURN, nên không bảo đảm kết nối giữa các mạng khác nhau.
